# ✨ John Doe’s Portfolio Website

A modern, interactive **portfolio website** showcasing projects, skills, and creativity with immersive 3D visuals, smooth animations, and responsive design. Built with **React + TypeScript**, this portfolio is fully modular, maintainable, and developer-friendly.

---

## 🌐 Live Demo
[View Live Portfolio](https://ebikemeese.github.io/John-Doe/)

---

## 🚀 Features

- **Interactive 3D Globe:** Visualize projects & connections with **Three.js**, **React Three Fiber**, and **Drei** 🌍  
- **Smooth Animations:** Powered by **GSAP** and **Framer Motion** for timeline-based effects 🎬  
- **Sleek & Responsive Design:** Styled with **TailwindCSS** + **Aceternity UI** for mobile and desktop devices 🎨  
- **Tilt & Motion Effects:** Includes **React Tilt / React Tilty** for interactive elements 🌀  
- **Vertical Timeline:** Showcase skills and experience with **React Vertical Timeline** 🧩  
- **Contact Integration:** EmailJS for functional contact forms ✉️  
- **Optimized Performance:** Built with **Vite** for fast development and build ⚡  
- **Developer-Friendly:** Modular, clean code architecture for easy maintenance 💻  

---

## 💻 Tech Stack

| Component | Technology / Library |
|-----------|--------------------|
| Frontend  | React, React DOM, React Router DOM, React Icons |
